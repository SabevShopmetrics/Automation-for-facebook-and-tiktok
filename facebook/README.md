# Facebook автопостинг

Публикува клиповете от Google Drive във Facebook страницата по график. Всяко видео се насрочва в самия Facebook. В часа на публикуване скриптът пуска първия коментар с линка към YouTube. Имейл идва само при проблем.

## Какво прави при всяко пускане

1. Чете графика (`data/schedule.csv` или Google Sheet).
2. За всеки ред в следващите 28 дни, който още не е качен:
   - проверява правилата от плана: подкана към премиерата преди 1 ноември и „пълния разговор“ след нея, 22 загинали, без Чернобил, 3–5 хаштага, правилна папка;
   - сваля файла от Drive и проверява дължината (Reel до 90 сек.);
   - качва го като **Reel** (9:16) или **видео** (4:5) и го насрочва във Facebook.
3. За всеки излязъл пост пуска първия коментар с линка към YouTube.
4. Ред с клип, който чака одобрение (клип 22), не се пуска, докато в графика няма `approved = да`.

Нищо не се качва два пъти. Направеното се пази в `data/state.json`.

## Настройка

1. Python 3.10+ (без допълнителни библиотеки).
2. Копирайте `.env.example` като `.env` и попълнете:
   - `FB_PAGE_ID` и `FB_PAGE_TOKEN` от колежката;
   - `YOUTUBE_URL` – линкът към премиерата;
   - по желание SMTP за имейл при проблем.
3. Проверка без публикуване:
   ```
   python run.py token
   python run.py check
   python run.py run
   ```
4. Сменете `DRY_RUN=0` в `.env`.
5. Пуснете автоматичното изпълнение на всеки 10 минути:
   - Windows: `powershell -ExecutionPolicy Bypass -File install_task.ps1`
   - Linux сървър (cron): `*/10 * * * * cd /път/до/facebook-autopost && python3 run.py run`

## Команди

| Команда | Какво прави |
| --- | --- |
| `python run.py check` | Проверява целия график и всички файлове. Не публикува. |
| `python run.py run` | Едно пускане: насрочва качванията и пуска коментарите. |
| `python run.py status` | Какво е предстоящо, насрочено и излязло. |
| `python run.py token` | Проверява ключа за страницата. |
| `python run.py run T1` | Пуска само посочените публикации. |
| `python run.py manual 04` | Отбелязва пост като пуснат на ръка. Скриптът го прескача. |

## Как се връща всичко назад

| Какво | Как |
| --- | --- |
| Един насрочен пост | `python run.py cancel T2` – изтрива го от Facebook и спира повторното му качване. |
| Всички насрочени постове | `python run.py cancel all` |
| Отменен пост обратно | `python run.py resume T2` – качва се при следващото пускане. |
| Автоматичното пускане | `powershell -ExecutionPolicy Bypass -File uninstall_task.ps1` |
| Достъпът до страницата | Facebook → Settings & privacy → Settings → Business integrations → posting-automation → Remove |
| Вече излязъл пост | Изтрива се на ръка от Meta Business Suite → Content. |

## Графикът

Една колона на публикация: `id`, `publish_at` (софийско време, `2026-11-02 18:30`), `type` (`reel` или `feed_video`), `drive_path`, `caption`, `first_comment` (`{youtube_url}` се заменя с линка), `needs_approval`, `approved`, `notes`.

За да не се пипа файлът ръчно: качете графика като Google Sheet, публикувайте го като CSV и сложете линка в `SCHEDULE_CSV_URL`.
