# Автоматично публикуване във Facebook и TikTok

Два отделни проекта, без общ код. Всеки чете клиповете и текстовете от Google Drive и графика от своя `data/schedule.csv`.

| Папка | Какво прави |
| --- | --- |
| [`facebook/`](facebook/) | Насрочва Reels и видео постове в самия Facebook през Graph API и пуска първия коментар с линка към YouTube. Работи сам на всеки 10 минути. |
| [`tiktok/`](tiktok/) | Страница-инструмент (http://localhost:8765): за всеки клип видео за сваляне, готов текст и час. Насрочването в TikTok Studio е ръчно, защото TikTok не одобрява вътрешни инструменти за публикуване през API. |

Изисквания: Python 3.10+ без допълнителни библиотеки.

Ключовете стоят само в `.env` (не е в репото). Шаблон: `.env.example` във всяка папка. Подробностите са в README-то на всяка папка.
